# Мишень — удалённая камера мишени

Одно приложение, две роли. Телефон у мишени отдаёт кадры, телефон стрелка ищет
новые пробоины относительно запомненной базы.

## Роли

**«Я камера у мишени»** — открывает камеру, поднимает HTTP-сервер на 8080.
На экране видно адрес: `http://<ip>:8080`.

* `GET /shot.jpg` — сделать снимок и вернуть JPEG
* `GET /info` — счётчик снимков и разрешение

Экран держится включённым, приложение нельзя выгружать из памяти.

**«Я пульт»** — вводит адрес камеры и работает:

* «Запомнить мишень» — 5 кадров, медиана, это база;
* «Снять и разобрать» — один кадр, сравнение с базой, новые пробоины оранжевым;
* «Авто» — то же каждые 2 секунды.

## Что делает разбор

1. Приводит кадр к размеру базы.
2. Ищет сдвиг (грубое выравнивание на 1/4 разрешения).
3. Подгоняет яркость по бумаге — снимает автоэкспозицию.
4. Считает разницу «стало темнее» и отбрасывает то, что и в базе было тёмным
   (кольца, яблоко, надписи).
5. Ищет связные пятна, фильтрует по диаметру в мм.
6. Считает группу, MOA, смещение СТП.

Калибровка `мм на пиксель` пока задана константой в `Detector.mmPerPx` (0,5).

## Сборка

APK собирается на GitHub Actions (`.github/workflows/build.yml`): push в `main`
или ручной запуск. Артефакт — `target-debug`.
